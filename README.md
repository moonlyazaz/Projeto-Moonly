# Projeto Moonly — Nível Intermediário

Exercícios do curso intermediário de desenvolvimento web (UniFil): layout com HTML + CSS, clonagens de interface e JavaScript.

## Aulas

| Pasta | Conteúdo |
|---|---|
| `AULA 01 - HTML + CSS` | HTML + CSS |
| `AULA 02 - CLONAGEM YOUTUBE` | Clonagem do YouTube |
| `AULA 03 - JAVASCRIPT` | JavaScript (calculadora de IMC) |
| `AULA 04 - Exercicio Card` | Exercício de card |
| `AULA 05 - CLONAGEM YOUTUBE REALISTA` | Clonagem do YouTube (versão realista) |
| `AULA 06 - JS` | JavaScript |

Imagens compartilhadas ficam em `img/`.

Demo: https://project-moonly.vercel.app

## Outros branches

- `unifil-basico`: primeira parte do curso (HTML, CSS e JavaScript básico).
- `main`: visão geral do projeto.
